What this is

A Pune hotel concierge chat. The browser talks to a FastAPI client. The client talks to Claude. Claude calls 16 MCP tools. Those tools read and write MongoDB — hotels, bookings, and users.

Dummy bookings are real database records, not memory. A guest can look up stays by 10-digit mobile number if they forget BK-…. There is no payment gateway.

How to run

  1. Confirm HOTEL-CHATBOT-CLIENT/.env has ANTHROPIC_API_KEY.
  2. Confirm HOTEL-CHATBOT-MCP/.env has MONGODB_URI and MONGODB_DB=hotel_chatbot.
  3. Start the client (it also starts the MCP server as a child process):
cd /Users/rohitshelar/Desktop/Hotel-ChatBot/HOTEL-CHATBOT-CLIENT
./.venv/bin/python app.py

Open http://127.0.0.1:8000. Stop with Ctrl+C, then start again after Python changes (no auto-reload).

Never paste the Claude key or MongoDB password into the chat UI, this HTML, or frontend JS.

Guest profile

First visit asks for name, email, and 10-digit mobile. That profile is stored in MongoDB users and kept in the session cookie until Log out. Bookings reuse those details — the chat does not ask again. 

GET  /auth/me       → { user }
POST /auth/guest    → save name, email, mobile
POST /auth/logout   → clear session
POST /chat          → 401 until the guest form is saved

How a question travels

Browser  The Desk UI
  → POST /chat   (httponly cookie hotel_sid, no API key)
  → guardrails   (jailbreak, topic, rate limit 20/min)
  → Claude       (system = CLAUDE.md + skills.md)
      if tool_use:
        → allowlist (16 names)
        → MCP stdio  HOTEL-CHATBOT-MCP/server.py
        → tools.py   → MongoDB hotel_chatbot
  → JSON { text, tools_called, blocked }
  → chat UI

MongoDB

Database name: hotel_chatbot. URI lives only in HOTEL-CHATBOT-MCP/.env.

CollectionKeyContents
hotelshotel_id e.g. HTL-PUN-01350 Pune hotels, rooms, rates, reviews, amenities.
users10-digit mobileName, email, booking_ids.
bookingsbooking_id e.g. BK-1001Hotel, room, dates, guest, status, total INR. Cancel sets status to cancelled; the row stays.
sessionscookie idLogged-in guest until Log out.
countersbooking_seqNext booking number.

create_booking requires name, email, and mobile. list_bookings with guest_phone is how “I forgot my booking id” works.

Guardrails

  • Browser never sees the Claude key or Mongo URI.
  • Jailbreaks and secret-shaped text are refused before Claude.
  • Only the 16 hotel tools may be called.
  • 20 requests per minute per session cookie.
  • CSP: scripts from 'self' only; connect-src 'self'.
